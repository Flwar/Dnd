# מפת הדרך — הכתר המנופץ

## ה־MVP הנוכחי

זרימת משחק מלאה בדפדפן: תפריט, יצירת דמות, דיאלוג, חקירה, משימה, ציוד, נתוני דמות וקרב תורות. מצב המשחק נשמר מקומית וממשק המשתמש בעברית וב־RTL.

## השלב הבא: משחק מקוון

- אימות משתמשים ופרופילים.
- מסד נתונים לקמפיינים, דמויות, ציוד והתקדמות.
- חדרי חבורה בזמן אמת וסנכרון מהלכים בצד השרת.
- הזמנות, צ'אט, התחברות מחדש ומנגנון הרשאות למנחה.
- בדיקות אוטומטיות, ניטור, גיבויים והגבלת קצב בקשות.

## הרחבת המשחק

- מפות אינטראקטיביות ונכסים מקוריים במקום סמלים זמניים.
- מערכת ציוד נגררת, יכולות לפי מקצוע והתקדמות דרגות.
- פרקים נוספים, שומר האבן, שבעת הרסיסים והחלטות ארוכות טווח.
- אפקטים קוליים, מוזיקה מקורית ונגישות מורחבת.
