# הכתר המנופץ

גרסת MVP למשחק תפקידים מקורי בדפדפן, בעברית מלאה ובכיוון RTL. הפרויקט בנוי ב־Next.js App Router, React, TypeScript, Tailwind CSS, Framer Motion ו־Lucide.

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחו `http://localhost:3000`.

## בניית גרסת ייצור

```bash
npm run build
npm start
```

## מה כלול

- תפריט ראשי, יצירת דמות עם שישה מקצועות ושישה גזעים ושמירה מקומית.
- מסך משחק רספונסיבי, דיאלוג מסתעף, משימה, תיק, דף דמות וקרב תורות.
- הגדרות, מצב מסך מלא, אישור איפוס שמירה ותשתית להרחבה לשפות נוספות.

## מגבלות ה־MVP

הדיוקנאות ומפת האזור הם סמלים ואיור CSS זמניים. משחק מקוון, שרת משותף, מוזיקה, גרירת ציוד והמשך העלילה המלא יתווספו בשלבים הבאים. השמירה כעת מקומית לדפדפן בלבד.

## פריסה ב־Vercel

ייבאו את המאגר ב־Vercel. זיהוי Next.js וה־Build נעשים אוטומטית ואין צורך במשתני סביבה.
