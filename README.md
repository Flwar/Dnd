# שערי הגורל

משחק תפקידים אפל לדפדפן, שנבנה מראש לעברית מלאה ולכתיבה מימין לשמאל.

## החוויה

- תפריט ראשי מלא עם משחק חדש, המשך, משחק מקוון, הגדרות והישגים.
- זירת קרב אינטראקטיבית עם קסמים, מספרי נזק, פסי חיים ואפקטים.
- חלונות דמות, ציוד, מיומנויות, קסמים, מקצוע, חבורה, משימות ויומן.
- מערכות מסחר, יצירה, דיאלוג, שלל, הודעות מערכת וצ׳אט.
- גרירה ושחרור של ציוד, לצד חלופת בחירה והנחה למסכי מגע.
- התאמה למחשב, לטאבלט ולנייד, כולל הפחתת תנועה וניגודיות מוגברת.

## הפעלה מקומית

נדרשת גרסת נוד עדכנית בהתאם להגדרה בקובץ החבילות.

```bash
npm install
npm run dev
```

בדיקה מלאה:

```bash
npm test
npm run lint
```
